# BOTANIA website

## The live site

Two files, plus the photo they use:

- `index.html` .... English page
- `pt.html` ....... Portuguese page
- `images/IMG_5567.jpg`

These are the files that get uploaded to GitHub. Edit these, nothing else.

## Publishing an update

The site is hosted on Netlify, which pulls from GitHub automatically.

1. Go to https://github.com/daianiof/BotanIA.github.io
2. Add file > Upload files
3. Drag in the changed file or files
4. Commit changes
5. Netlify redeploys on its own in a minute or two

Then hard-refresh the live site with Cmd+Shift+R, or you will see a cached
copy of the old version and think it failed.

If something goes wrong, Netlify keeps every past deploy. Open the Deploys
tab, click an earlier one, and press "Publish deploy" to roll back.
